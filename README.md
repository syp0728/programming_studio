# 🚀 Object-Oriented Programming & Data Structures Practices

Welcome to the comprehensive repository for **Data Structures (C++)** and **Java Programming** practical laboratory exercises. This repository serves as a consolidated space containing hands-on lab exercises, coding tests, and projects designed to reinforce fundamental and advanced computer science concepts.

---

## 📌 Course Focus

### 🔹 Data Structures (DS)
* Emphasizes practical exercises and labs that reinforce topics from the core Data Structures course.
* Provides hands-on practice with object-oriented programming (C++ syntax), dynamic memory allocation, pointers, implementation of abstract data types (ADTs), and foundational sorting algorithms.

### 🔹 Java Programming
* Focuses on practical application and labs that align with object-oriented programming methodologies within the Java ecosystem.
* Progresses from basic syntax control flows to advanced architectural concepts, culminating in building a fully functional CRUD-based management system.

## 📝 Usage & Installation

To run the practice codes locally, ensure you have the appropriate compilers and environments set up:
* **For DS (C++):** A modern C++ compiler supporting `C++11` or higher (e.g., GCC/G++, Clang, MSVC).
* **For Java:** Java Development Kit (JDK 11 or higher recommended).
