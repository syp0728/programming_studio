
## **[프로젝트 주제 및 개요]**
* **주제:** 개인 구독 서비스 관리 프로그램 (Subscription Management System)
* **선택 이유:** 최근 넷플릭스, 유튜브 프리미엄, 음악 스트리밍 등 다양한 구독 서비스를 이용하는 사용자가 늘어남에 따라, 매달 지출되는 고정 비용과 결제일을 한눈에 관리하고 효율적으로 인원을 공유하기 위해 이 주제를 선택했습니다.

---

### **1. 데이터 필드 구성 설명**
각 구독 서비스를 정의하기 위해 `ServiceItem` 클래스에 다음 5가지 필드를 구성했습니다.
* **name (String):** 서비스 이름 (예: 넷플릭스, 유튜브)
* **price (int):** 월 결제 금액
* **date (String):** 다음 결제 예정일 (YYYY-MM-DD 형식)
* **person (int):** 구독 공유 인원수
* **category (String):** 서비스 분류 (영상, 음악, 도서 등)

### **2. 클래스 구조 설명**
* **Main:** 프로그램의 진입점으로 사용자의 명령어를 입력받고 전체 흐름을 제어합니다.
* **iCRUD (Interface):** 데이터 관리의 기본 규격(생성, 추가, 수정, 삭제, 출력)을 정의합니다.
* **ServiceCRUD:** 인터페이스를 구현하며, `ArrayList<ServiceItem>`을 사용하여 실제 데이터를 관리하고 정렬 로직을 포함합니다.
* **ServiceItem:** 개별 구독 서비스의 정보를 담는 객체 모델입니다.

### **3. Interface 사용 이유**
`iCRUD` 인터페이스를 사용함으로써 프로그램이 갖추어야 할 필수 기능을 구조화했습니다. 이를 통해 추후 파일 저장 기능이 추가된 `FileServiceCRUD` 등으로 확장하더라도 동일한 메서드 구조를 유지할 수 있어 코드의 유지보수성과 확장성이 높아집니다.

### **4. Overriding / Overloading 적용 부분**
* **Overriding (재정의):**
    * `iCRUD` 인터페이스의 추상 메서드들을 `ServiceCRUD`에서 실제 비즈니스 로직으로 구현했습니다.
    * `ServiceItem` 클래스에서 `Object` 클래스의 `toString()` 메서드를 재정의하여 콘솔 출력 시 데이터가 표 형식으로 정렬되도록 설정했습니다.
* **Overloading (중복정의):**
    * `ServiceCRUD` 클래스의 **`printAll()` 메서드를 오버로딩**하여 구현했습니다.
    * 매개변수가 없는 `printAll()`은 전체 리스트를 출력하고, 매개변수가 있는 `printAll(String category)`은 사용자가 입력한 특정 카테고리에 해당하는 항목만 필터링하여 출력하도록 설계했습니다.

### **5. 추가 기능 3가지 설명**
1. **카테고리 필터링 검색:** 오버로딩된 `printAll(String category)` 메서드를 활용하여 `ls [카테고리명]` 입력 시 원하는 분류의 구독 서비스만 선별해서 볼 수 있는 검색 기능을 추가했습니다.
2. **다중 조건 정렬:** `Comparator`를 활용해 이름순(`ls name`) 또는 결제일순(`ls date`)으로 정렬할 수 있으며, `desc` 키워드를 결합해 내림차순 정렬도 가능합니다.
3. **실시간 중복 체크:** `isDuplicated()` 메서드를 통해 새로운 서비스를 추가할 때 동일한 이름의 서비스가 중복 등록되는 것을 방지하여 데이터의 무결성을 유지합니다.

### **6. 구현 과정에서 어려웠던 점**
1. **Scanner 버퍼 문제:** `nextInt()` 이후 `nextLine()`을 호출할 때 버퍼에 남은 엔터 값 때문에 입력이 건너뛰어지는 현상이 발생했습니다. 이를 해결하기 위해 `s.nextLine()`을 추가하여 버퍼를 비워주는 처리를 했습니다.
2. **콘솔 정렬 포맷팅:** 각기 다른 데이터 길이에 상관없이 제목줄과 데이터줄의 수직 라인을 맞추기 위해 `String.format()`의 고정 폭 할당 기능을 세밀하게 조정하는 과정이 까다로웠습니다.

## **[수업 회고 및 느낀점]**

### **1. 프로젝트를 진행하면서 새롭게 배운 점**
단순히 데이터를 입력받는 것을 넘어, `String.format()`을 이용해 콘솔 화면을 표(Table) 형태로 예쁘게 출력하는 방법을 익혔습니다. 또한 인터페이스와 구현체(Implements)의 관계를 코드로 직접 짜보며 객체 지향 프로그래밍의 구조를 이해하게 되었습니다.

### **2. 본인이 생각하는 본인 코드의 부족한 점**
* **데이터 유지력:** 현재는 프로그램 종료 시 데이터가 휘발됩니다. `PrintWriter` 등을 활용한 파일 입출력(`File IO`) 기능을 추가하여 데이터를 영구적으로 저장하는 기능이 보완되어야 합니다.
* **성능 최적화:** 현재는 반복문 내에서 직접 출력하고 있으나, 대량의 데이터를 처리할 때는 `StringBuilder`를 사용하여 문자열을 결합한 뒤 한 번에 출력하는 방식이 더 효율적임을 알게 되었습니다.

### **3. 수업 방식에 대한 건의사항**
이론으로만 배우던 인터페이스나 정렬 알고리즘을 실제 실습 프로젝트에 적용해 볼 수 있어서 유익했습니다. 앞으로 실제 현업에서 자주 쓰이는 디자인 패턴이나 외부 라이브러리 활용법에 대해서도 더 배울 수 있는 기회가 있으면 좋겠습니다.
